# Code-Along Structure

This folder contains three local-only workshop exercises.

## Exercises

### 01-data-intake-review
Turn unknown files into a trustworthy intake report.

- `incoming/` — starter files to inspect
- `prompts/` — prompt text to paste into OpenClaw
- `outputs/` — generated markdown reports
- `expected/` — output shape and section outline

### 02-operational-memory
Turn work residue into daily and weekly momentum docs.

- `inbox/` — starter notes and work residue
- `prompts/` — daily and weekly prompts
- `outputs/` — generated logs and summaries
- `schedule/` — heartbeat/cron notes for the walkthrough

### 03-offline-communications-triage
Turn exported mail into an action list.

- `eml/` — starter exported email files
- `prompts/` — triage prompt
- `outputs/` — generated triage report
- `expected/` — output shape and section outline

### mission-control
Reserved for a simple dashboard or final exercise extension.
